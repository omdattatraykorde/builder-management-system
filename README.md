# Builder Management System

A web-based management system designed to help construction businesses manage their projects, customers, workers, materials, expenses, payments, and daily site activities from a centralized platform.

## Features

- User authentication and registration
- Dashboard with project and financial information
- Customer management
- Project management
- Worker management
- Material management
- Expense management
- Payment management
- Worker assignment
- Attendance management
- Daily construction progress tracking
- Site photo upload and gallery
- Reports and dashboard information

## Technology Stack

### Frontend
- React.js
- Vite
- JavaScript
- CSS
- Axios

### Backend
- Python
- FastAPI
- SQLAlchemy
- JWT Authentication

### Database
- PostgreSQL

### Version Control
- Git
- GitHub
